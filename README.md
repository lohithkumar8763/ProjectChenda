Mayoora Vadhyakala

A modern and responsive website created for Mayoora Vadhyakala, a traditional Chenda Melam group.

🌐 Live Website: https://mayoora-vadhyakala.vercel.app

📌 About the Project

This website provides information about Mayoora Vadhyakala and showcases their Chenda Melam performances and services.

The website allows visitors to:

- Learn about the group
- View performances and activities
- Explore available services
- View photos and other content
- Contact the group for events and programs

✨ Features

- Responsive design
- Mobile-friendly interface
- Clean and simple UI
- Performance and gallery section
- About section
- Contact section
- Easy navigation
- Fast loading
- Deployed using Vercel

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Vite
- Vercel

💻 Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/mayoora-vadhyakala.git

2. Open the project

cd mayoora-vadhyakala

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL shown in the terminal.
